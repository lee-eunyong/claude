# Claude Code로 배우는 AI 코딩 입문

## 1️⃣ 누가 들어야 하나요?

- 코딩을 배워보고 싶지만 어디서부터 시작해야 할지 막막한 초보자
- 아이디어는 있는데 개발 방법을 몰라 실행에 옮기지 못하는 기획자
- ChatGPT로 코딩해봤지만 프로젝트까지 완성이 안 되는 분
- AI 코딩 도구로 개발 능력을 갖추고 싶은 도전자

---

## 2️⃣ 어떤 강의인가요?

실제 프로그램을 만들며 Claude Code에 대해 배우는 입문 강의입니다.

- 간단한 계산기부터 게임, 웹페이지까지 다양한 프로젝트를 함께 완성합니다.
- Git 명령어 없이도 버전 관리를 자동화하고 배포까지 한 번에 처리하는 방법을 배웁니다.
- 코딩 지식 없이도 Claude Code와 함께 개발하는 방법을 경험할 수 있는 강의입니다.

---

## 3️⃣ 어떤 것을 배우나요?

### Claude Code 기초

- Claude Code 설치 및 환경 설정
- 첫 대화를 통한 AI 코딩 경험
- 자연어 기반 개발 방식 이해

### 프로그램 개발 실습

- 간단한 프로그램 제작
- 자연어로 기능 구현하기
- AI와 협업하는 개발 프로세스 학습

### 버전 관리 및 협업

- Git 버전 관리를 자연어로 처리하는 방법
- 변경 이력 관리 자동화
- 개발 생산성 향상 노하우

### 프로젝트 완성 및 배포

- 게임 프로젝트 제작
- 웹페이지 제작
- GitHub Pages를 활용한 배포
- 기획부터 배포까지 전체 개발 프로세스 경험

---

## 4️⃣ 완강하면 어떤 일이 생길까요?

- AI 시대에 필요한 핵심 개발 역량을 확보할 수 있습니다.
- 복잡한 코드 작성 없이 아이디어를 실제 서비스로 구현할 수 있습니다.
- 반복적인 코딩 작업을 자동화하여 창의적인 기획과 문제 해결에 집중할 수 있습니다.
- AI를 활용한 실전 개발 경험을 바탕으로 다양한 프로젝트를 스스로 수행할 수 있습니다.
- 기획자, 비개발자도 AI와 함께 서비스를 제작하고 배포할 수 있는 자신감을 얻게 됩니다.

---

## 🚀 이런 분들께 추천합니다

- AI를 활용한 개발에 관심 있는 분
- 프로그래밍 입문자
- 업무 자동화를 고민하는 직장인
- 아이디어를 직접 서비스로 만들어보고 싶은 창업 준비자
- ChatGPT, Claude 등 생성형 AI를 업무에 적극 활용하고 싶은 분
